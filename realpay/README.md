# 도깨비방망이 🔨

**긱워커의 불규칙한 소득과 세금을 매달 관리하는 AI Agent**
제8회 KB Future Finance A.I. Challenge 2026 출품작 · MVP 프로토타입

> 통장 입금 내역만으로 미래 소득을 예측하고, 5월 세금 폭탄을 미리 막아주는 긱워커 전용 금융 비서.

## 이런 문제를 풉니다

긱워커는 소득이 불규칙하고 정산이 지연돼 자금 관리가 어렵습니다. 3.3% 원천징수만으로는 5월 종합소득세를 대비하기 어렵고, 업종코드가 잘못 분류되면 안 내도 될 세금을 냅니다. **도깨비방망이는 입금 내역 하나로 이걸 매달 자동으로 관리합니다.**

## 핵심 기능

### 📊 소득 안정성 진단 (상위 가치)
매달 내 소득이 얼마나 안정적인지 4개 지표로 자가진단합니다.
`변동계수` · `소득 추세` · `계절성 진폭` · `활성 플랫폼 수` → **안정 / 보통 / 불안정** 수준을 한눈에.

### 🔮 다음 달 소득 예측 (LightGBM + SHAP)
과거 입금 패턴을 학습해 다음 달 소득을 예측하고, **왜 그렇게 예측했는지 근거까지** 보여줍니다.

### 💰 세금 예측 & 자동 대비
예상 연소득으로 5월에 낼 종합소득세를 미리 계산하고, **입금마다 조금씩 세금 대비금을 적립**하는 시뮬레이션을 보여줍니다.

### 🎯 긱워커 특화 절세
플랫폼에 맞는 업종코드 후보를 제시해, 같은 소득이라도 세금을 줄일 수 있는 코드를 알려줍니다.

### 📝 AI 리포트 (LLM)
위 수치와 근거를 **사람이 읽는 자연어 리포트**로 요약해줍니다. (진단 → 대비 → 최적화)

## 3개 화면

| 화면 | 무엇을 |
|---|---|
| **온보딩 설문** | 데이터 없는 신규 사용자도 7문항으로 시작 (콜드스타트 대응) |
| **대시보드** | 세금 금고 잔고 · 이번 달 소득 · 다음 달 예측 · 실제 vs 예측 그래프 |
| **리포트** | 연 예상세액 · 환급 · 업종코드 추천 · SHAP 근거 · 안정성 4지표 · LLM 요약 |

## 빠른 시작


## 소득 예측 모델

**다음 달 소득 = LightGBM (pooled panel)** — 개인별 모델을 따로 만들지 않고 450명 × 24개월을 하나의 학습 테이블로 합쳐 "이런 최근 흐름 + 계절 + 유형이면 다음 달은 대략 이렇다"는 패턴을 학습합니다. 덕분에 **이력이 4개월뿐인 워커도** 다른 워커에게서 배운 패턴으로 예측할 수 있습니다.

**피처 16종**
- 소득 시차 `lag1~3_income` · 이동평균/변동성 `roll3_mean` `roll6_mean` `roll3_std`
- 근무 `workdays` `workdays_ratio` `n_platforms_active`
- 계절 `is_holiday_season` `month_sin` `month_cos` `months_since_start`
- 유형(원핫) `pattern_regular / seasonal / irregular`

**검증 2겹**
1. **정량** — worker 단위 5-fold group split(리키지 차단)에서 나이브 베이스라인(최근 3개월 평균) 대비 MAE 개선
2. **설명** — 매 예측마다 SHAP으로 기여 피처를 분해해 근거 공개 (블랙박스 아님)

## 목데이터 생성

23년 플랫폼종사자 실태조사(고용노동부·한국고용정보원) 파라미터를 근거로 합성합니다.

- **직군 분포** — 운송·배달 / 전문서비스 / 컴퓨터 단순작업 / 가사·청소·돌봄 / 창작 / IT / 기타 (직군별 모집단 비율·월 순수입 반영)
- **변동 유형** — 규칙형 `CV 0.10~0.25` / 계절형 `0.20~0.40` / 불규칙·간헐형 `0.40~0.80` (CV = 월소득 표준편차 ÷ 월평균)
- **기간** — 24개월 (계절 패턴이 두 번 반영되는 길이)
- **콜드스타트** — 설문으로 유사 워커 코호트 평균과 본인 예상치를 블렌딩. 데이터가 쌓이면 관측 가중치 `min(1, 유효 활동주 / 12)`로 실측 비중↑ (4주 33% → 8주 67% → 12주+ 100%)

## 중요한 한계와 안전 가정

> [!IMPORTANT]
> 목데이터를 사용하는 **시뮬레이션**입니다. 실제 계좌를 연결·조회하지 않고, 자금을 이체·보관하지 않으며, 세무 신고·자문을 제공하지 않습니다. 신고용 업종코드 결정과 세무 자문은 구현 범위 밖입니다.

- **세액은 AI가 아니라 검증된 세법 룰이 계산**합니다. 세율표·경비율은 국세청 홈택스 고시값과 전수 대조했습니다. 데모는 2,400만원 기준·기본공제 등 제한된 항목만 반영하며, 인적·특별세액공제·국민연금 공제·기준경비율 증빙 차감은 미반영합니다.
- **단순화 가정은 모두 보수적(세금을 많게 잡는) 방향**입니다. 적게 떼면 5월 폭탄(실패), 많이 떼면 환급(보너스)이라 "5월 폭탄 방지" 목적에 정렬했습니다. 실서비스 전환 시 세무 전문가 검수가 전제입니다.
- **업종코드는 세액순 추천이 아닙니다.** 대표·검토 후보만 제시하며, 최종 신고 코드는 실제 업무와 지급명세서로 본인이 결정합니다.
- **연간 소득은 "다음 달 예측 × 잔여 개월"로 단순화**(단순 연환산, 누적 실적 미반영). 실서비스는 월별 순차 재귀 예측이 필요합니다.
- **대비액은 3.3% 원천징수 완료를 가정**하고 부족 예상분만 계산합니다.
- **모든 계좌·금고·적립 표시는 가상 계산값**입니다. 실제 자금 이동·보관은 없습니다.
- **모델은 합성 목데이터로만 평가**했습니다. 5-fold MAE 약 59.1만원·MAPE 약 38.8%(`model/artifacts/metrics.json`)는 실데이터 성능을 보증하지 않으며, SHAP은 기여도이지 인과 보증이 아닙니다.
